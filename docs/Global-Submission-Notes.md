# TradePilot Global Submission Notes

## 1. 当前版本定位

当前提交版为：

```text
TradePilot Global v0.1｜跨境选品前置决策基础版
```

本轮仅完成独立副本、品牌改造、首页定位、报告品牌、提交说明和演示说明更新。没有新增跨境字段，也没有修改任何核心算法。

## 2. 国内版与跨境版隔离

- 国内版原始压缩包保持不动；
- 跨境版独立目录为 `TradePilot-Global-Submit-v0.1`；
- 后续建议单独建立 `tradepilot-global` 仓库或独立分支；
- 不覆盖国内版部署地址；
- 不 push、不创建 PR、不合并 main。

## 3. 本轮未修改的核心逻辑

- 原评分算法；
- 图片识别接口；
- LLM 接口；
- Supabase 逻辑；
- 产品库核心保存结构；
- PK；
- 复盘；
- 图表；
- `package.json`；
- `package-lock.json`；
- `vercel.json`。

## 4. 旧记录兼容

固定 localStorage key 保持不变：

```text
tradepilot_local_records
```

旧产品库记录仍可读取，不需要迁移。

## 5. 当前报告边界

当前报告展示基础利润、MOQ、首批备货压力、风险、内容测款和复盘建议。国际物流、平台佣金、税费、退货成本和合规认证尚未自动计算，实际备货前需要人工核验。

## 6. 历史文件说明

根目录无扩展名文件 `download` 为旧版 Supabase SQL 残留，表名与当前运行代码不一致。当前运行逻辑不要依赖该文件。本轮保留该文件，不进行清理。
