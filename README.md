# TradePilot Global｜跨境拿货搭子：小商品出海选品与爆款测款智能体

## 1. 项目简介

TradePilot Global 是一个面向义乌小商品卖家、小微跨境电商团队和新手跨境创业者的工作流式 AI 选品决策智能体。

当前提交版定位为：

> **小商品出海选品前置决策基础版**

项目继承 TradePilot AI 国内版的稳定能力，帮助用户在正式投入跨境备货前，先完成商品识别、基础利润测算、MOQ 与备货压力判断、风险提示、内容测款、供应商沟通、候选产品库、候选产品 PK 和测款复盘。

项目口号：

> **出海前，先算清楚。**

当前版本不夸大为全自动爆款预测系统，也不会自动下单、自动付款或伪造平台真实数据。国际物流、平台佣金、税费、目标市场与合规专项分析将在后续版本中逐步接入。

## 4. 当前能力边界

TradePilot Global 当前最准确的架构表述是：

> **规则评分 + 商品视觉识别 + LLM 策略补充 + 工作流式 Agent + 多个 Skills 能力模块**

利润率、成本、MOQ、首批备货资金和风险评分等确定性指标由规则算法计算，以保证稳定性和可解释性。视觉模型负责辅助识别商品图片。LLM 用于补充进货策略、内容测款方向和复盘总结，不覆盖原评分，也不伪造平台真实数据。

当前基础版尚未自动完成：

- 目标国家与目标平台专项判断；
- 国际物流成本计算；
- 平台佣金与支付手续费计算；
- 税费与关税计算；
- 跨境退货成本计算；
- CE、FDA、RoHS 等认证匹配；
- TikTok Shop、Shopee、Amazon 的真实平台数据采集；
- 自动下单或自动付款。

实际备货前，用户仍需人工核验国际物流、平台规则、税费、合规认证和供应商信息。

---

## 5. 合规原则

项目严格遵守以下边界：

- 不伪造淘宝、1688、抖音、小红书、TikTok Shop、Shopee、Amazon 等平台的真实销量、播放量、点赞量、成交量、价格或热度数据；
- 不进行违规爬虫；
- 不绕过登录、验证码或反爬机制；
- 平台数据优先使用人工填写、用户粘贴链接、CSV 导入、搜索入口或未来合规 API；
- 高风险采购动作保留用户确认；
- 不自动下单；
- 不自动付款。

## 8. 存储说明

游客模式使用浏览器 localStorage 保存记录，固定 key 为：

```text
tradepilot_local_records
```

该 key 在跨境基础版中保持不变，因此旧产品库记录仍可读取。Supabase 云端同步仍为可选能力。

## 9. 在线体验说明

当前代码包为可部署提交版。部署到 Vercel、腾讯云 CloudBase 或比赛 ECS 后，请将最终线上地址填写到提交平台。
